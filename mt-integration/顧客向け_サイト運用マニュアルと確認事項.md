## 1. サイトの文言・画像の修正方法（御社ご自身で修正いただけます）

### 1-1. テキスト（文言）の修正

1、MakerTown管理画面にログインします。

2、「ページマスタ」を開き、修正したいページ（トップ・商品一覧など）を「編集」で開きます。

3、ページ内の「HTML」ブロックの「編集」を開きます。

4、直したいダミー文言を探し、実際の文章に書き換えます。（ご注意：山かっこ `< >` で囲まれた部分＝タグは触らず、**文字だけ**を書き換えてください）

5、「保存」を押し、実ページを開いて `Ctrl+F5`（強制再読み込み）で反映を確認します。

### 1-2. 画像（人物写真・素材など）の修正

画像は「リソース」という置き場の中身を差し替えるだけです（URL・HTMLは触りません）。差し替えたい画像は、サイト上の「検証（Inspect）」で表示されるコードを手がかりに探します。

**【手順】**

1、サイト上で、差し替えたい画像を**右クリック** →「**検証（Inspect）**」を選びます。

2、開いたパネルで `<img src="https://print-world.jp/resource/○○○">` を見つけ、`/resource/` の**後ろの文字列（○○○＝画像のコード）をコピー**します。

3、管理画面の「**リソースマスタ**」→「**リソース一覧**」を開き、右上の「表示件数」を「**100**」にします。

4、キーボードの `Ctrl+F`（ブラウザ検索）を押し、コピーしたコードを貼り付けます。「URL」列で一致する行がハイライトされます。（見つからない場合は「Next »」で次ページに進み、再度 `Ctrl+F`）

5、その行の**左端のID（数字）をクリック**し、「リソース編集」を開きます。

6、「**Choose File（ファイルを選択）**」で新しい画像を選び、「**保存**」を押します。

7、URL（コード）は変わりません。元のページを `Ctrl+F5` で確認すると、新しい画像に切り替わっています。

**【ご注意】**

1、新しい画像は、差し替え前と**同じ向き・縦横比**にするとレイアウトが崩れにくいです。

2、対応形式は jpg・png・gif・svg です。

3、ロゴなどヘッダー・フッターの画像も、同じ手順（リソース）で差し替えできます。

## 2. プリント価格について（ご確認・ご回答のお願い）

プリント価格表を拝受しました。数量帯ごとの自動計算まで整っており、大変助かります。商品登録にあたり、以下の5点をご確認ください。

1、この価格は**どの印刷方法（加工手法）**のものでしょうか（例：インクジェット、シルク、転写、刺繍）。複数の方法を提供される場合は、**方法ごとの価格**が必要になります。

2、価格は**色数によって変わりますか**（シルク等は色数で変動する場合があります）。インクジェット等でフルカラー一律であれば不要です。

3、数量帯について、**「30〜49枚」が抜けている**ように見えます（10〜29 の次が 50〜99）。この区分の扱い（どちらかに含める／追加する）をお知らせください。

4、加工位置は**「左胸・右胸・胸中央・背中中央」の4か所で全て**でしょうか。他に提供される位置（袖・背中上・ポケット等）があればお知らせください。

5、記載の価格は**税抜・税込のどちら**でしょうか。

## 3. ヘッダーのデザインについて（ご確認・ご選択のお願い）

現在のヘッダーは、御社のデザイン（ロゴ＋電話／お問い合わせ／LINE＋メニューボタン）を反映しています。**カート・会員ログイン機能はすでに組み込み済み**です。

一方、MakerTown標準のショップ（例：メイクル）では、上部にカート・会員アイコンを大きく配置し、その下に「商品一覧／用途別提案／ご利用ガイド…」の横並びメニューと検索ボックスがあります。この点が現在のヘッダーと異なります。

つきましては、ヘッダーの方向性を次の3つからご選択ください。

1、**現在のデザインを踏襲**（連絡ボタン＋メニューボタン中心）。その上で、カート・会員アイコンを**もう少し目立たせる**だけにする。

2、**MakerTown標準に寄せる**。＝カート・会員アイコンを上部に大きく配置し、**横並びのナビメニュー**と**検索ボックス**を追加する。

3、**ハイブリッド**（現在の見た目を保ちつつ、横並びメニュー・検索・目立つカート／会員アイコンを追加する）。

あわせて、以下もお知らせいただけますと、スムーズに調整できます。

1、**横並びのナビメニュー**（商品一覧・用途別提案・ご利用ガイド 等）を、PCで常時表示したいか。

2、**検索ボックス**をヘッダーに付けたいか。

3、**カート・会員アイコン**を、メイクルのように大きく目立たせたいか（現状は小さめです）。

## 4. デザイン（CSS）の変更方法（御社ご自身で調整いただけます）

色・文字サイズ・余白など「見た目（CSS）」も、御社ご自身で調整いただけるようにしました。

**最初にお読みください（安全の仕組み）**

1、Print World の**標準デザインCSSは別の場所にあり、この作業では一切変更しません**。御社が書き込むのは「上書き専用の枠」だけです。

2、上書き枠は最後に読み込まれ、**書いた分だけ**標準デザインに勝って反映されます。**空のままなら今の見た目は一切変わりません。**

3、元に戻したいときは、**書き足した行を消すだけ**で元通りになります。標準デザインは壊れません。

### 4-0. 準備（最初に一度だけ）

1、私どもがお渡しする「カスタムCSS枠」（`custom-css-footer` のコード）を、管理画面 →「ページテーマ」→「**フッタ**」Twig の**一番下**に貼り付けて保存します。（設置は最初の一度だけです）

2、以降、デザイン変更は**この枠の中（「編集エリア」）だけ**を編集します。枠の外は触らないでください。

### 4-1. 変更のしかた（基本の流れ）

「1-2. 画像の修正」で使った**検証（Inspect）**と同じ要領です。

1、サイト上で、変えたい部分を**右クリック** →「**検証（Inspect）**」を選びます。

2、ハイライトされたコードの中の **`class="○○○"`** の**○○○（クラス名）をメモ**します。（複数あるときは、変えたい部分に一番近いものを選びます）

3、管理画面 →「ページテーマ」→「フッタ」Twig を開き、カスタムCSS枠の「編集エリア」に、下の「よく使う変更例」を参考に**1行足します**。

4、「保存」を押し、実ページを `Ctrl+F5`（強制再読み込み）で確認します。

5、うまくいかない／戻したいときは、**足した行を消して**保存すれば元に戻ります。

### 4-2. よく使う変更例（コピーして数字・色を変えるだけ）

`クラス名` の部分を、4-1でメモしたクラス名に置き換えてお使いください。行末の **`!important` は消さないでください**（標準CSSに勝つために必要です）。

1、文字の色を変える：`.クラス名 { color: #d8001a !important; }`

2、背景の色を変える：`.クラス名 { background-color: #ffd54a !important; }`

3、文字の大きさを変える：`.クラス名 { font-size: 18px !important; }`

4、ある部分を隠す（非表示）：`.クラス名 { display: none !important; }`

5、余白（すき間）を変える：`.クラス名 { padding-top: 40px !important; }`

（色は `#` で始まる6桁のカラーコードです。Googleで「カラーピッカー」と検索すると、好きな色のコードを取得できます）

### 4-3. ご注意（安全にお使いいただくために）

1、編集は**カスタムCSS枠の「編集エリア」の中だけ**にしてください。枠の外・他のTwig・HTMLブロックは触らないでください。

2、1回に**1か所ずつ**変更し、都度 `Ctrl+F5` で確認すると、原因がわかりやすく安全です。

3、色・文字サイズ・余白・表示/非表示 などの**部分的な調整**は御社で安全に行えます。一方、**レイアウトの大きな作り替え**（配置の入れ替え等）はデザインが崩れやすいため、その場合は「こう変えたい」とご連絡いただければ私どもで対応いたします。

4、正しく書いても**まれに変更が反映されない箇所**があります（デザイン保持のため特別に固定している部分です）。その場合は無理に重ねず、「この部分をこう変えたい」とご連絡ください。すぐに対応いたします。

5、万一おかしくなっても、**編集エリアを空にして保存**すれば、必ず元のデザインに戻ります。
