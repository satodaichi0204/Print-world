プリントワールド サイト 編集マニュアル

御社ご自身で「文言・画像・デザイン（色や文字）」を修正いただけます

このマニュアルでは、公開後にサイトの文言・画像・見た目（色や文字サイズ）を、御社ご自身で修正する方法をご案内します。
むずかしい知識は必要ありません。手順どおりに進めれば大丈夫です。そして何より―― 元のデザインが壊れない仕組みになっていますので、安心してお試しください。

1文言（文章）を直す

各ページの文章は、管理画面の「HTMLブロック」で書き換えられます。

  1. MakerTown管理画面にログインします。
  2. 「ページマスタ」を開き、直したいページ（トップ・商品一覧など）を「編集」で開きます。
  3. ページ内の「HTML」ブロックの「編集」を開きます。
  4. 直したい文章を探して、書き換えます。
  5. 「保存」を押し、実際のページを Ctrl+F5（強制再読み込み）で確認します。
ここに注意 山かっこ < > で囲まれた部分（＝タグ）は触らず、文字だけを書き換えてください。

2画像（写真・素材）を差し替える

画像は「リソース」という置き場の中身を入れ替えるだけです。URLやHTMLは触りません。

  1. サイト上で、差し替えたい画像を右クリック →「検証（Inspect）」を選びます。
  2. 表示されたコードの中の src="https://print-world.jp/resource/○○○" を見つけ、/resource/ の後ろの文字列（○○○）をコピーします。
  3. 管理画面の「リソースマスタ」→「リソース一覧」を開き、右上の「表示件数」を「100」にします。
  4. Ctrl+F（ページ内検索）で、コピーした文字列を貼り付けて探します。（無ければ「Next »」で次ページへ）
  5. 見つかった行の左端のID（数字）をクリックし、「リソース編集」を開きます。
  6. 「Choose File（ファイルを選択）」で新しい画像を選び、「保存」します。
  7. 元のページを Ctrl+F5 で確認すると、新しい画像に変わっています。
安心ポイント URL（コード）は変わらないので、リンク切れの心配はありません。新しい画像は、元と同じ向き・縦横比にすると、レイアウトがきれいに保てます。（対応形式：jpg・png・gif・svg）

3見た目（色・文字サイズなど）を変える

色・文字の大きさ・余白などの「見た目」も、御社ご自身で調整できます。まずは、なぜ安心して試せるのかをご説明します。

絶対に壊れない仕組みです サイトの元のデザインは別の場所にあり、この作業では一切変更しません。御社が書き込むのは「上書き専用のスペース」だけです。
  • 書いた分だけ、上書きして反映されます。
  • スペースが空なら、今の見た目はまったく変わりません。
  • 元に戻したいときは、書いた行を消すだけ。元のデザインは無傷です。

準備（最初に一度だけ）

  1. お渡しする「カスタムCSS枠」のコードを、管理画面 →「ページテーマ」→「フッタ」の一番下に貼り付けて保存します。設置は一度だけ
  2. 以降、見た目の調整はこの枠の中（「編集エリア」）だけを編集します。

変え方（基本の流れ）

「2. 画像の差し替え」で使った検証（Inspect）と同じ感覚です。

  1. サイト上で、変えたい部分を右クリック →「検証（Inspect）」を選びます。
  2. ハイライトされたコードの class="○○○" の ○○○（クラス名）をメモします。（複数あるときは、変えたい部分に一番近いもの）
  3. 「フッタ」のカスタムCSS枠の「編集エリア」に、下の「変更例」を参考に1行足します。
  4. 「保存」→ 実ページを Ctrl+F5 で確認します。
  5. 戻したいときは、足した行を消して保存すれば元通りです。

よく使う変更例（コピーして、クラス名と数字・色を変えるだけ）

クラス名 の部分を、メモしたクラス名に置き換えてください。行末の !important は消さないでください（元のデザインに上書きするために必要です）。

① 文字の色を変える
.クラス名 { color: #d8001a !important; }
② 背景の色を変える
.クラス名 { background-color: #ffd54a !important; }
③ 文字の大きさを変える
.クラス名 { font-size: 18px !important; }
④ ある部分を隠す（非表示）
.クラス名 { display: none !important; }
⑤ 余白（すき間）を変える
.クラス名 { padding-top: 40px !important; }
色コードの調べ方 色は # で始まる6桁のコードです。Googleで「カラーピッカー」と検索すると、好きな色のコードをかんたんに取得できます。
安全にお使いいただくために
  • 編集はカスタムCSS枠の「編集エリア」の中だけにしてください。
  • 1回に1か所ずつ変えて、都度 Ctrl+F5 で確認すると安全です。
  • 正しく書いてもまれに反映されない部分があります（デザイン保持のため固定している箇所です）。その場合は無理をせず、「この部分をこう変えたい」とご連絡ください。すぐ対応します。
  • 大きなレイアウトの作り替えは崩れやすいので、ご希望をお知らせいただければ私どもで対応します。
困ったら、これで必ず元通り 万一おかしくなっても、編集エリアを空にして保存すれば、必ず元のデザインに戻ります。

?よくあるご質問

操作を間違えて、サイトが壊れてしまわないか不安です。

ご安心ください。文言・画像・CSSのどの作業も、元データを直接壊さない仕組みです。特に見た目（CSS）は「上書き専用スペース」を空にすれば必ず元に戻ります。

変更したのに、画面に反映されません。

まず Ctrl+F5（強制再読み込み）をお試しください。それでも変わらない場合は、クラス名の綴り、または !important の付け忘れをご確認ください。それでも反映されない箇所は「保護された部分」ですので、ご連絡ください。

クラス名がたくさんあって、どれを選べばいいか分かりません。

「検証（Inspect）」で青くハイライトされる範囲を見ながら、変えたい部分に一番近いクラス名を選んでください。うまくいかなければ、別のクラス名でお試しいただくか、私どもにお任せください。

自分でやるのが不安なので、お願いしたいです。

もちろんです。「どのページの、どこを、どう変えたいか」をお知らせいただければ、私どもで対応いたします。

ご不明な点は、お気軽にお問い合わせください。
